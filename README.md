# Health Tag

Client-side Fabric mod that shows player health below name tags.

## Supported Versions

- Minecraft 26.2
- Minecraft 26.1.2
- Minecraft 26.1.1
- Minecraft 26.1
- Minecraft 1.21.11

## Build

Use the multiversion build script from the parent project, or build this project directly:

```powershell
.\gradlew.bat build
```

This mod depends on Fabric Loader only.
